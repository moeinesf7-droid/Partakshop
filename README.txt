پارتاک — نسخه ۳ فروشگاه

این بسته شامل فروشگاه RTL، سبد خرید، ثبت سفارش، پیگیری سفارش، API با Pages Functions، دیتابیس D1 و پنل مدیریت است.

برای راه‌اندازی واقعی: پروژه را از GitHub به Cloudflare Pages متصل کنید، D1 را بسازید و migration را اجرا کنید، سپس Secret با نام ADMIN_KEY بسازید و دامنه را وصل کنید.

درگاه پرداخت و SMS/Email عمداً فعلاً متصل نشده‌اند و بعداً قابل اضافه شدن هستند.

هشدار: تا قبل از تنظیم ADMIN_KEY، اتصال D1 و دامنه، این بسته را فروشگاه تولیدی تلقی نکنید.
